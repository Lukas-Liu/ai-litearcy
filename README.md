# AI Literacy Atlas

An interactive explorer for comparing AI literacy frameworks and drafting a framework for a specific context.

Four frameworks are pooled into one rotatable sphere of 48 components:

- Long & Magerko (2020), What is AI literacy? Competencies and design considerations, CHI 2020
- Ng, Leung, Chu, & Qiao (2021), Conceptualizing AI literacy: An exploratory review, Computers and Education: Artificial Intelligence
- UNESCO (2024), AI competency framework for students
- UNESCO (2024), AI competency framework for teachers

Choosing assumptions about who is learning, why it matters, how it is taught, and what you value collapses the sphere onto a plane centered on that context. The components inside the boundary form a draft framework.

Component descriptions are paraphrased. Theme placements and projection weights are interpretive design choices meant to be questioned.

## Run it

Open `index.html` in a browser. No build step or server is needed.
